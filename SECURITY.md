# Security Policy

## Supported code

Security fixes apply to the current default branch and the latest maintained version of this repository.

## Reporting a vulnerability

Please do **not** disclose security-sensitive details in a public issue.

If GitHub Private Vulnerability Reporting is enabled for this repository, use it to submit the report privately. Otherwise, contact the maintainer through the contact channels listed on the GitHub profile and share only the minimum information needed to establish a private communication channel before sending exploit details, credentials, personal data, or other sensitive material.

When reporting, include:

- A clear description of the issue.
- The affected file, route, component, or version.
- Reproduction steps that do not expose third-party data.
- The potential impact.
- A suggested remediation, if known.

## Sensitive data

Do not commit API keys, passwords, tokens, private customer information, production exports, or environment files. Use environment variables and local configuration for secrets.

## Scope

Reports concerning third-party platforms, packages, hosting providers, or external services should also be reported to the relevant vendor when appropriate.
