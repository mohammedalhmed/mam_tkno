# سجل إصدار إعادة تصميم واجهات وتجربة مستخدم MAM_Tkno

**التاريخ:** 12 سبتمبر 2026  
**النطاق:** واجهة ثابتة عربية RTL لموقع MAM_Tkno، من دون تغيير نموذج البيانات الموثق أو إضافة خدمات خادمية.

## ملخص التنفيذ

أعيد تصميم الموقع وفق اتجاه **Product Systems Atelier** المعتمد: ورق عاجي للمقاطع السردية، حبر داكن لمختبرات الواجهة ودعوات القرار، وCyan Signal كلون إجراء وحالة. ركّزت التحديثات على نقل الزائر من التعرف إلى القرار ثم طلب المشروع، بدلاً من عرض أقسام متشابهة منفصلة.

| المجال | ما تم تحديثه | أثر تجربة المستخدم |
|---|---|---|
| نظام التصميم | Alexandria للعناوين، IBM Plex Sans Arabic للنصوص، Manrope للوسوم؛ أسطح عاجية/داكنة وCyan للإجراء | هرمية عربية أوضح وتباين مستقر عبر الصفحات |
| التنقل والواجهة الافتتاحية | هيدر RTL، قائمة جوال قابلة للإغلاق، مؤشر تقدم، واجهة افتتاحية تحريرية ودعوات قصيرة | مسار مباشر إلى الخدمات أو الأعمال أو الطلب |
| الخدمات | مسار قرار للقطاعين، ولوحة **قرار / دليل / نطاق** داخل صفحات الفئات | تقليل غموض نقطة البداية قبل استعراض الخدمات |
| المشاريع ودراسات الحالة | معرض تحريري، بصمة مستقلة لكل مشروع، شريط مراجعة سريع، وإيقاع متفاوت للمشكلة والحل والمخرجات | تصبح طريقة العمل قابلة للقراءة قبل تفاصيل المعاينة |
| طلب المشروع والتواصل | نموذج خطوات واضح، ملخص قبل الإرسال، رابط واتساب برسالة منظمة وبديل بريد إلكتروني | احتكاك أقل مع بقاء القنوات المتاحة في النسخة الثابتة |
| الوصول والحركة | حلقات تركيز مرئية، مساحات لمس محسنة، مراقب ظهور آمن، واحترام `prefers-reduced-motion` | واجهة قابلة للاستخدام بلوحة المفاتيح وعلى اللمس دون إخفاء المحتوى |

## قرارات التصميم المنفذة

أصبحت الصفحات الداخلية تستخدم طبقات **قرار / دليل / نطاق** بدل الاعتماد على بطاقات خدمة متساوية فقط. تعرض دراسة الحالة في البداية ملخص مراجعة سريعاً يفرّق بين قرار الواجهة والدليل الوصفي والنطاق الموثق؛ ولا تضيف هذه الطبقات أرقام أداء أو ادعاءات تجارية جديدة.

احتفظت المشاريع بألوان داعمة مستقلة داخل إطار MAM_Tkno. يبقى Cyan لون الفعل العام، بينما تظهر ألوان المشروع في وسومه وحدوده ومعالجته التحريرية، كي لا تبدو الصفحات قوالب متشابهة مع تغيير الاسم فقط.

## التحقق المنجز

| الفحص | النتيجة |
|---|---|
| `pnpm run verify:seo` | ناجح؛ تم التحقق من 3 دراسات حالة و3 مسارات صور |
| `pnpm exec tsc --noEmit` | ناجح؛ لا أخطاء TypeScript |
| `pnpm run build` | ناجح؛ يظهر تحذير حجم chunk الرئيسي فقط، وليس فشل بناء |
| معاينة سطح المكتب | مراجعة الصفحة الرئيسية والخدمات ودراسة الحالة، ثم تطبيق ملاحظات تصميمية في تمريرة واحدة |
| معاينة الهاتف | فحص `/` و`/services/design` و`/case-studies/nerfona` و`/case-studies/altaj` على 390×844 |
| معاينة الجهاز اللوحي | فحص `/` و`/services/technology` و`/case-studies/bellabox` على 768×1024 |

## حدود الإصدار وخطوات لاحقة

يبقى الموقع frontend-only؛ لا توجد قاعدة بيانات أو CRM أو إرسال مضمون من الخادم. يظل واتساب مع البريد الإلكتروني قناة الطلب الحالية. يوصى في الإصدار اللاحق بإجراء تدقيق Lighthouse فعلي، واختبار يدوي شامل لتدفق واتساب ولوحة المفاتيح في متصفحات متعددة، وإضافة وسائط أصلية موثقة لكل دراسة حالة عند توافرها.
