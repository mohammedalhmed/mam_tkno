# مصدر بيانات المشروع

هذا الملف يحدد أين توجد كل معلومة وما الذي يُسمح بادعائه. لا تكرر بيانات المنتج في مكونات متعددة إذا كان لها مصدر مركزي.

## مصادر الحقيقة

| المجال | المصدر | قاعدة التحديث |
|---|---|---|
| أنواع المواقع والصفحات والإضافات والكلمات الدالة | `client/src/lib/website-types.ts` | أي تعديل على نوع أو توصية يبدأ هنا ثم يُراجع في docs |
| المشاريع وروابطها وبيانات التواصل | `client/src/lib/portfolio-data.ts` | لا تُغير الروابط إلا بعد تحقق عام جديد |
| عنوان الصفحة وSEO وSchema | `client/index.html` و`client/src/lib/seo.ts` | يحافظ على canonical وJSON-LD و6–8 كلمات مركزة |
| رحلة brief وحالته | `client/src/components/WebsiteTypes.tsx` | أي تغيير يجب أن يحدّث الاختبار البصري |
| الحقائق العامة عن المشاريع | `project_research.md` | يضاف المصدر وتاريخ المراجعة، ولا يُعرض كبيانات حية |
| قرارات UX والعمارة | `docs/` و`SPEC-MAM_Tkno.md` | تُحدّث قبل الكود عند تغير النطاق |

## تعريف المنتج

MAM_Tkno ليس منصة بناء مواقع للعميل ولا نظام تسعير. هو **واجهة اكتشاف نطاق** تساعد العميل على الوصول إلى brief قابل للمراجعة البشرية.

## الأنواع الستة

| المعرّف | النوع | نتيجة العمل الأساسية |
|---|---|---|
| `corporate` | مواقع الشركات والخدمات | ثقة + استشارة/تواصل/طلب عرض |
| `ecommerce` | المتاجر الإلكترونية | اكتشاف المنتج + شراء + شحن/استلام |
| `landing` | صفحات الهبوط والحملات | تحويل واحد قابل للقياس |
| `portfolio` | الأعمال والملفات الشخصية | عرض الدليل + فرصة عمل أو استشارة |
| `booking` | الحجز والخدمات | اختيار خدمة وموعد + تأكيد |
| `saas` | تطبيقات الويب ولوحات التحكم | إنجاز مهام وبيانات داخل نظام |

## قواعد التوصيات

- المتجر: `shop-payment` و`shop-search`.
- الحجز: `booking-notifications` و`booking-auth`.
- الشركات: `corporate-crm` و`corporate-notifications`.
- الهبوط: `landing-form` و`landing-tracking`.
- البورتفوليو: `portfolio-testimonials` و`portfolio-booking`.
- SaaS: `saas-auth` و`saas-analytics`.

التوصية لا تعني أن الوظيفة منفذة في هذا الموقع. هي عنصر نطاق يضاف إلى brief ويمكن للعميل إلغاؤه.

## بيانات الاتصال

المصدر الوحيد هو `contactDetails` داخل `portfolio-data.ts`. لا تكرر البريد أو الهاتف أو روابط الحسابات في المكونات. عند تعديلها، راجع JSON-LD وContact وFooter واختبارات SEO.

## قاموس brief

| الحقل | إلزامي | الغرض |
|---|---:|---|
| اسم/عنوان الموقع | نعم | تثبيت هوية المشروع |
| المجال | نعم | تشغيل اقتراح النوع والصفحات والإضافات |
| الأسئلة المتخصصة | حسب النوع | فهم المنتج أو النشاط قبل الدراسة |
| الصفحات الأساسية | محددة مبدئيًا وقابلة للتعديل | تشكيل النطاق |
| الإضافات | مقترحة وقابلة للإلغاء | التقاط الوظائف المؤثرة في التكلفة |
| تفاصيل مساعدة | لا | الشعار والروابط والألوان والملاحظات |

## بيانات لا يجوز اختلاقها

لا تُضاف أسعار أو مدد أو شهادات أو أرقام عملاء أو تكاملات حية أو بيانات خاصة بالمشاريع دون مصدر أو اعتماد. كل وصف لمشروع خارجي يجب أن يوضح أنه مبني على مصدر عام وتاريخ تحقق.
