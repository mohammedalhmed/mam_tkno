# متطلبات المنتج

## الهدف

تمكين عميل عربي من تحويل فكرة موقع عامة إلى brief أولي منظم، مع الحفاظ على دور الموقع كواجهة ثقة وعرض أعمال.

## المتطلبات الوظيفية

### F01 — العرض والثقة
- يعرض الموقع هوية MAM_Tkno ورسالة القيمة ومجالات العمل.
- يعرض المشاريع الثلاثة مع الوصف والدور وقرار الواجهة والرابط العام.
- يعرض وسائل التواصل ومعلومات الخدمة في العالم العربي.

### F02 — كتالوج الأنواع
- يعرض ستة أنواع مواقع في بطاقات واضحة.
- لكل بطاقة اسم عربي وإنجليزي وملخص ومؤشرات وصفحات وإضافات.
- فتح البطاقة يفتح modal في نفس الصفحة دون تغيير المسار.

### F03 — اقتراح النوع
- عند إدخال مجال من ثلاثة أحرف أو أكثر، تُطابق الكلمات الدالة العربية/الإنجليزية.
- عند وجود تطابق، يتغير النوع والصفحات الأساسية تلقائيًا.
- تظهر رسالة توضح النوع وعبارات المطابقة وعدد الصفحات.
- اختيار بطاقة يدويًا يعمل كـ override حتى يغير العميل المجال مرة أخرى.

### F04 — بناء brief
- الخطوة الأولى: اسم الموقع والمجال، وكلاهما مطلوب.
- الخطوة الثانية: أسئلة متخصصة حسب النوع.
- الخطوة الثالثة: صفحات أساسية محددة مسبقًا وقابلة للإلغاء.
- الخطوة الرابعة: إضافات مقترحة تلقائيًا وإضافات أخرى قابلة للاختيار.
- الخطوة الخامسة: ملاحظات ومراجعة ثم إرسال.

### F05 — اقتراح الإضافات
- المتجر يقترح الدفع والبحث/الفلاتر.
- الحجز يقترح التذكيرات وحساب العميل.
- تظهر شارة وسبب مختصر، ويمكن إلغاء كل خيار.
- عند تغيير النوع تُعاد تهيئة الصفحات والإضافات الخاصة بالنوع الجديد.

### F06 — التسليم
- يولد التطبيق رسالة واتساب تشمل النوع، المجال، البيانات المتخصصة، الصفحات، الإضافات، والملاحظات.
- لا يرسل البيانات تلقائيًا إلى خادم ولا يدّعي تسعيرًا نهائيًا.

## المتطلبات غير الوظيفية

- RTL والعربية أولًا.
- استجابة عند 390 و768 و1280 بكسل دون overflow.
- لوحة مفاتيح: Escape يغلق modal، والتركيز يعود إلى زر الفتح.
- backdrop مموه يمنع تفاعل وتمرير الخلفية.
- reduced motion يحترم تفضيل المستخدم.
- صور المشاريع تحمل alt وصفيًا.
- canonical وJSON-LD وOG وTwitter وrobots محفوظة.
- الحالة الحالية client-only ولا تتطلب أسرارًا أو backend.

## معايير القبول

| المعيار | طريقة التحقق |
|---|---|
| اقتراح متجر إلكتروني | كتابة «متجر إلكتروني» ثم تحقق WEB-02 والصفحات والإضافات |
| اقتراح حجز | اختيار/كتابة عيادة ومواعيد ثم تحقق WEB-05 والتذكيرات |
| إلغاء الاقتراح | uncheck ثم تحقق من تغير الحالة وإمكانية إعادة الاختيار |
| عدم التداخل | قياس dialog مقابل header في الاختبار البصري |
| عدم overflow | `scrollWidth === viewport` عند 390 و768 |
| سلامة الحزمة | `pnpm run check`, `pnpm run build`, `pnpm run verify:seo`, `pnpm run test:visual` |

## ما لا يعتبر نجاحًا

- عرض خيارات كثيرة بلا تفسير.
- اختيار وظائف لا علاقة لها بنوع الموقع.
- إرسال رسالة ناقصة أو فتح صفحة جديدة داخل الموقع.
- تغيير الهوية الزرقاء إلى أبيض/أسود عام.
