# تحليل قالب Canva المرجعي — 2026-09-14

**المرجع:** <https://mamtkno.my.canva.site/mam>

## ملاحظات مؤكدة من المعاينة

- يستخدم القالب واجهة عربية داكنة عالية التباين، مع شريط علوي بسيط وقائمة مختصرة قابلة للفتح على الهاتف.
- تبدأ الرحلة بلافتة عرض قصيرة، ثم hero مقسّم بصريًا إلى بطاقة زرقاء شفافة كبيرة وصورة جهاز محمول/موقع، مع عناصر ثلاثية الأبعاد زرقاء متداخلة.
- البنية التحريرية تعتمد عنوانًا كبيرًا، وصفًا قصيرًا، ودعوة إجراء واحدة واضحة، ثم أسئلة مشكلة متتابعة تقود إلى شرح منهج العمل.
- تظهر البطاقات الثانوية بإطارات رفيعة وزوايا دائرية كبيرة وتباين قوي بين الأسود والأزرق والأبيض.
- تنقل المرجع يشمل: الصفحة الرئيسية، الخدمات، الأسئلة الشائعة، والتواصل.

## حدود المواءمة مع MAM_Tkno

- ستستلهم MAM_Tkno مبدأ hero المقسّم، اللافتة المختصرة، التكوين الداكن عالي التباين، ومسار المشكلة إلى الحل.
- لن تُنسخ هوية المرجع أو نصوصه أو صوره أو أصوله؛ ستبقى هوية MAM_Tkno ومحتوى البرمجة والتصميم الجرافيكي والبيانات الموثقة كما هي.
- سيبقى Cyan Signal لون الإجراء الأساسي وفق قرارات العلامة، مع عدم استخدام أصول Canva أو الإيحاء بارتباط رسمي بها.
- يجب أن تحافظ جميع المسارات ودراسات الحالة ونموذج واتساب والبيانات الدلالية الحالية على عملها بعد التنفيذ.

## حدود التنفيذ والتحقق

- **يحافظ التنفيذ على:** بيانات MAM_Tkno، العربية RTL، المسارات الحالية، زر واتساب، Schema وSEO، ومكوّنات الحوار والوصول الموجودة.
- **لا يتضمن التنفيذ:** نسخ النصوص أو الصور أو الرسومات أو العلامة الخاصة بالمرجع، إضافة شهادات أو نتائج كمية، أو تغيير الخلفية التقنية للمشروع الثابت.
- **يُقبل التحديث عند:** نجاح `pnpm run verify:seo` و`pnpm run check` و`pnpm run build`، واكتمال المعاينة على الهاتف واللوحي وسطح المكتب، وعدم ظهور تمرير أفقي أو عنصر تفاعلي غير قابل للتركيز.
