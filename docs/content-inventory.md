# MAM_Tkno — مخزون محتوى دراسات الحالة

هذا الملف يحدد حالة المحتوى المستخدم في صفحات دراسات الحالة بعد Release 2. يعتمد العرض الحالي على الصفحات العامة للمشاريع والبيانات الموجودة في المستودع، ولا يضيف أرقام أداء أو شهادات عملاء غير موثقة.

## سياسة المحتوى

تُعرض النتيجة بصياغة وصفية عندما لا تتوفر بيانات منشورة قابلة للتحقق. أي رقم أو شهادة أو ادعاء تجاري جديد يجب أن يمر بمراجعة واعتماد قبل إضافته إلى `client/src/lib/case-studies.ts`.

## حالة التنفيذ

أضيف قالب موحّد لدراسة الحالة، ومسار داخلي لكل مشروع، وإجراء مشاركة يستخدم Web Share API مع fallback لنسخ الرابط، كما يمرر إجراء «طلب مشروع مشابه» معرف المشروع والخدمة إلى نموذج طلب السعر. تم التحقق من TypeScript وبناء الإنتاج والمعاينة على 1280×720 و390×844.

## سياسة اعتماد المصادر العامة

اعتمد المستخدم المحتوى الحالي لدراسات الحالة دون إضافة أرقام. لذلك تبقى BellaBox وNERFONA وALTAJ PLUS جاهزة للعرض بصياغة وصفية فقط، بينما تظل المؤشرات الرقمية والشهادات والنتائج التجارية خارج النشر حتى يقدّم المستخدم مصدرًا أو اعتمادًا صريحًا.

تمت مراجعة الحسابات العامة المتاحة. GitHub وTelegram وFacebook أتاحوا معلومات عامة محدودة، بينما أعاد Instagram صفحة تسجيل دخول. استُخدمت هذه المراجعة لتوثيق الروابط والحسابات فقط، ولم تُنقل أوصاف شخصية أو أرقام متغيرة للمتابعين إلى Schema أو صفحات MAM_Tkno التجارية. تفاصيل المصادر محفوظة في `docs/source-notes-github.md`.
