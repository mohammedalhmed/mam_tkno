# MAM_Tkno — مخزون محتوى دراسات الحالة

هذا الملف يحدد حالة المحتوى المستخدم في صفحات دراسات الحالة بعد Release 2. يعتمد العرض الحالي على الصفحات العامة للمشاريع والبيانات الموجودة في المستودع، ولا يضيف أرقام أداء أو شهادات عملاء غير موثقة.

| المشروع | الحالة | الجاهز حاليًا | الناقص أو الذي يحتاج اعتمادًا |
|---|---|---|---|
| BellaBox | جاهز للعرض العام، مع اعتماد إضافي للنتائج الرقمية | العنوان، القطاع، الملخص، المشكلة، الحل، نطاق العمل، صورة المعاينة، رابط الموقع، الخدمات المرتبطة | مؤشرات الأداء الرقمية، لقطات إضافية إن وجدت، اعتماد صياغة النتائج التجارية |
| NERFONA | جاهز للعرض العام، مع اعتماد إضافي للنتائج الرقمية | العنوان، القطاع، الملخص، المشكلة، الحل، نطاق العمل، صورة المعاينة، رابط الموقع، الخدمات المرتبطة | مؤشرات الأداء الرقمية، تفاصيل الملكية والمسؤوليات، لقطات إضافية |
| ALTAJ PLUS | جاهز للعرض العام، مع اعتماد إضافي للنتائج الرقمية | العنوان، القطاع، الملخص، المشكلة، الحل، نطاق العمل، صورة المعاينة، رابط الموقع، الخدمات المرتبطة | بيانات التحويل أو العملاء المحتملين، تفاصيل قبل/بعد، اعتماد النتائج التجارية |

## سياسة المحتوى

تُعرض النتيجة بصياغة وصفية عندما لا تتوفر بيانات منشورة قابلة للتحقق. أي رقم أو شهادة أو ادعاء تجاري جديد يجب أن يمر بمراجعة واعتماد قبل إضافته إلى `client/src/lib/case-studies.ts`.

## حالة التنفيذ

أضيف قالب موحّد لدراسة الحالة، ومسار داخلي لكل مشروع، وإجراء مشاركة يستخدم Web Share API مع fallback لنسخ الرابط، كما يمرر إجراء «طلب مشروع مشابه» معرف المشروع والخدمة إلى نموذج طلب السعر. تم التحقق من TypeScript وبناء الإنتاج والمعاينة على 1280×720 و390×844.
