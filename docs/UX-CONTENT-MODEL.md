# نموذج تجربة المستخدم والمحتوى

## مبدأ التجربة

**افهم → اختر → خصص → راجع → ناقش.** لا يطلب الموقع من العميل معلومات قبل أن يشرح له لماذا يحتاجها.

## الرحلة

1. **الواجهة الافتتاحية:** يفهم العميل أن MAM_Tkno يبني واجهات وثيمات ومتاجر ومنتجات رقمية.
2. **الخدمات والمشاريع:** يرى طريقة التفكير والدليل العملي.
3. **خريطة أنواع المواقع:** يقارن بين ستة أنواع بدل البحث في قائمة خدمات مجردة.
4. **اختيار التصنيف:** يفتح modal فوق الصفحة مع backdrop مموه.
5. **المجال:** يكتب العميل المجال؛ يظهر النوع المقترح والصفحات والإضافات المبدئية.
6. **التخصيص:** يراجع الأسئلة والصفحات والإضافات ويلغي ما لا يحتاجه.
7. **المراجعة:** يرى ملخصًا قابلًا للفهم ويضيف سياقًا اختياريًا.
8. **واتساب:** يرسل brief لمراجعة بشرية ودراسة نطاق وعرض سعر لاحق.

## أسلوب كتابة الحقول

- السؤال الواحد يطلب قرارًا واحدًا.
- placeholder يعطي مثالًا، ولا يكرر label.
- النجمة تعني أن الحقل ضروري فعلًا.
- الاختيار المسبق يسمى «مقترح» لا «مطلوب».
- لا نستخدم لغة تسعير نهائي أو وعود زمنية قبل الدراسة.

## مكونات بطاقة النوع

| المنطقة | المحتوى |
|---|---|
| الهوية | code + اسم عربي + اسم إنجليزي |
| الوعد | ملخص نتيجة النوع |
| النطاق | عدد الصفحات والإضافات وبيانات brief |
| الأساس | أول الصفحات المقترحة |
| التخصيص | أول الإضافات المتاحة |
| الإجراء | «خصص هذا النوع» أو «اختر هذا التصنيف» |

## مكونات modal

- زر إغلاق في زاوية ثابتة.
- ملخص النوع في العمود الجانبي على الشاشات الكبيرة.
- شريط خطوات من 5 مراحل.
- على الهاتف: عمود واحد قابل للتمرير، مع مساحة آمنة أسفل الهيدر.
- رسالة اقتراح النوع بعد إدخال المجال.
- رسالة اقتراح الإضافات في بداية الخطوة الرابعة.

## حالات الاقتراح

| الحالة | السلوك |
|---|---|
| نص أقل من 3 أحرف | لا اقتراح ولا تغيير نوع |
| نص عام بلا كلمة دالة | يبقى النوع الحالي |
| تطابق واضح | يغير النوع والصفحات والإضافات ويعرض السبب |
| اختيار يدوي | يضبط النوع ويعيد الصفحات والإضافات التابعة له |
| تغيير المجال بعد اختيار يدوي | يعود الاقتراح التلقائي للعمل |
| إلغاء إضافة مقترحة | لا يعاد تفعيلها إلا بإجراء يدوي أو تغيير النوع |

## نبرة المحتوى

عملية، واضحة، عربية، غير متضخمة، وتشرح الحدود. نستعمل «نراجع ونجهز دراسة» بدل «نضمن نتيجة» أو «السعر يبدأ من» دون اعتماد.
