

## Feature Slice: Project reference documentation

### Build order
1. توحيد تعريف المنتج من بورتفوليو فقط إلى بورتفوليو + كتالوج أنواع + باني brief.
2. إنشاء ميثاق ومصدر بيانات ومتطلبات UX وعمارة وخارطة تطوير ومخططات Mermaid.
3. تحديث README وSPEC وSEO ووصف الحزمة لتطابق الفكرة الجديدة.
4. مراجعة التعارض بين البيانات القديمة والمصادر الحالية، ثم تشغيل الفحوص وحفظ checkpoint.

### Exit gate
توجد حزمة توثيق عربية قابلة للقراءة قبل لمس الكود، وتكون أسماء المنتج ووصفه ومسار brief وحدوده متطابقة في docs وSPEC وREADME وSEO.
